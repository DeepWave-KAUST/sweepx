# Task spec schema (generated)

Generated by `scripts/gen_spec_reference.py` from sweepx 0.4.1. Do not edit by hand; re-run the script after upgrading.

Every model forbids unknown keys (`extra="forbid"`): a misspelt key is a validation error. Cross-field rules (which keys a path refuses, one-of sources, ...) are not in these tables; they are enforced by validators and summarised in `workflows.md`.

Path resolution: string values expand `$VAR` / `${VAR}` (an unset variable is an error). Keys named `coeff_shards`, `disk_dir`, `npy_path`, `output_dir`, `path`, `receivers_file`, `sources_file` (any depth), and `mask`, `seabed` inside `water:`, are resolved relative to the YAML file. Every other path (`plan_path`, `index_path`, `data_mask_path`, `topography`, `init_from`, ...) is relative to the working directory of the process.
